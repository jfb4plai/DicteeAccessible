Comment les parasites seraient choisis

Règle « -é ou -er » : autres formes du même verbe (-é, -ée, -er, -ez). Proposées par l'IA, relues par l'enseignant.

Sans règle : mots proches choisis par l'enseignant (ex. vent / vend).

Contrôle par le code : un parasite ne doit jamais être égal à un mot de la phrase. Que le parasite soit bien une autre forme du même verbe n'est pas vérifiable par le code : c'est l'enseignant qui valide.
